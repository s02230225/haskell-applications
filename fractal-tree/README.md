# Фрактальное дерево на Gloss

Визуализация и анимация фрактального дерева с рекурсивной геометрией и обработкой событий.

- [Исходники](src/) и [точка входа](app/).
- [Настройки Stack](stack.yaml) и [описание пакета](package.yaml).

Из этой папки:

```bash
stack build
stack run
```

Управление: `i`/`u` — скорость симуляции, `p` — пауза, `c` — сброс,
`k`/`j` — скорость роста, `1`/`2` — режим отображения.
Требуются Stack/GHC и графические зависимости Gloss.
