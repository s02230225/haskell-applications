# Функциональные упражнения на Haskell

Подборка упражнений с отдельной точкой входа и настройками сборки.

- [Исходники](src/), [точка входа](app/) и [тесты](test/).
- [Настройки Stack](stack.yaml) и [описание пакета](package.yaml).

Из этой папки:

```bash
stack build
stack run
```

Версия GHC и набор зависимостей задаются настройками проекта.
