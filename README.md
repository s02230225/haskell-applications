# Графика и интерфейсы на Haskell

**Haskell · Gloss · Monomer**

Подборка приложений с функциональной моделью состояния и обработкой событий.

- `fractal-tree` — визуализация и анимация фрактального дерева на Gloss; рекурсивная геометрия, управление скоростью и режимами отображения.
- `desktop-app` — список задач на Monomer: модель, события и построение интерфейса.
- `functional-exercises` — дополнительные функциональные упражнения.

Запуск выбранного приложения из его собственной папки:

```bash
stack build
stack run
```

Нужны Stack/GHC и графические библиотеки выбранного проекта. Для Gloss управление описано в src/Lib.hs: i/u — скорость симуляции, p — пауза, c — сброс, k/j — скорость роста, 1/2 — режим отображения.

Monomer-приложение развивается на основе monomer-starter. Исходная лицензия и сведения об авторах каркаса сохранены; ресурсы шрифтов находятся в assets/fonts.
